## 의사결정 문서화 원칙

1. 논의 끝에 결론이 나와도 **바로 기록하지 않는다.** 먼저 사용자에게 "이거 노트에 남길까요? 어떤 내용으로 남길까요?"라고 물어보고, 확인을 받은 뒤에 기록한다.
2. 해당 세션의 기록 내용을 대표하는 내용으로 md 파일의 제목을 정하고, 문서 내부의 첫줄에는 md 파일이 생성된 날짜와 시간(ex.2026-08-26 pm11:00)을 표시한다
3. 기록할 때는 짧은 불렛 형식으로만 남긴다. 긴 문단 설명 금지. 기본 틀:
   - 결정:
   - 이유: (간략하게)
   - 기각한 대안: (있는 경우만, 한 줄)
4. `claude-notes/` 폴더 아래 관련 로그 파일에 이어서 쓴다.
5. 시간이 걸린 오류 해결도 같은 방식(먼저 기록 여부·범위 확인 → 불렛 요약)으로 남긴다.
6. **노트 파일이든 다른 무엇이든, 사용자가 명시적으로 요청하지 않은 파일 생성/수정을 먼저 하지 않는다.** 애매하면 만들기 전에 반드시 먼저 질문한다.
