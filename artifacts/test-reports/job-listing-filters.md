## 4. 미검증 항목

- **마이그레이션 후 실제 DB 값 포맷**(deadline이 `...T14:59:59Z` 형태로 바뀌었는지)은 사용자가
  마이그레이션 적용을 확인했다고 알려온 것을 신뢰했고, 별도로 Supabase 행을 직접 조회해
  재확인하지는 않았다.
- **career_level 백필**(`server/jobs/backfill-career-level.ts`)은 dry-run/apply 모두 미실행 —
  기존 스크래핑된 1574건은 아직 `career_level`이 전부 null일 가능성이 높다. 신입/경력 필터
  자체(select UI, 쿼리 `eq` 조건)는 코드 리뷰로 정확성 확인됨(T5/T4), 다만 값이 채워진
  데이터로 실제 필터링 결과 건수까지는 이번 QA에서 확인하지 않았다.
- 반응형(360/768/1280)·다크모드 대비·safe-area·터치 타깃은 이번 라운드에서 별도 확인 안 함
  (이 브랜치는 시각 리스타일이 아니라 기능 변경 위주라 우선순위 낮음으로 판단, 필요시 후속 요청).
