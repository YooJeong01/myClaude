# QA 3라운드: 분석상세·지원동기 화면 + 사이드바 폴딩 실제 클릭 확인

round2에서 캡처 스크립트의 카드 클릭이 실제 네비게이션을 못 타서 미확인이었던 두 화면과,
정적 스크린샷 위주였던 사이드바 폴딩을 이번엔 **카드 클릭 대신 기존 분석 ID로 직접 URL 이동**,
**테마 토글·사이드바 토글 버튼을 실제로 클릭**하는 방식으로 재확인했다.

## 방법

- `pnpm start`(프로덕션 빌드, 23:59 빌드본 — 마지막 코드 커밋 `eaf6dc5`(21:47) 이후라 최신 상태)
  로 서버 기동.
- Playwright 스크립트를 `e2e/`에 임시로 넣어 실행 후 즉시 삭제(round2와 동일 패턴, 커밋 안 함).
- 로그인: `SCRAPE_OWNER_USER_ID` 매직링크. 분석 상세는 카드 클릭이 아니라 해당 사용자의 최신
  `company_analyses.id`로 직접 URL 이동.
- 사이드바는 `getByRole("button", { name: "사이드바 접기" })` / `"사이드바 펼치기"`를 실제
  클릭해 확인(스크린샷 3장: 펼침→접힘→재펼침).

## 확인 완료 (문제 없음)

- **분석상세** (`/dashboard/analyses/[id]`, 라이트+다크): 카드형 섹션(회사개요·재무요약·최근
  뉴스·애널리스트 시각·리스크·지원동기 매칭 소재·지난 분석) 전부 정상 렌더. 다크모드 전환도
  토큰 기반이라 깨짐 없음. 노션풍 톤(얇은 보더, 낮은 채도) 일관됨.
- **지원동기 매칭** (`/dashboard/analyses/[id]/motivation`): 레이아웃 정상(좌측 경험 선택 +
  우측 분석 요약 카드, 하단 지원동기 이력 리스트). "저장된 경험이 없습니다" 빈 상태는 테스트
  계정의 `career_experiences`가 현재 0건이라 뜨는 정상 동작(컴포넌트 결함 아님) — 지원동기
  이력 리스트 자체는 과거 생성분이 정상적으로 나열됨.
- **사이드바 폴딩 실제 클릭**: 펼침→"사이드바 접기" 클릭→접힘(아이콘 레일만 남고 토글
  화살표 방향도 `<`→`>`로 반전)→"사이드바 펼치기" 클릭→원상 재펼침까지 3단계 전부 레이아웃
  깨짐 없이 정상 동작. round1/2에서 수정한 동적 `css()` 버그·토글 접근불가 버그 모두 실제
  클릭 기준으로 재발 없음 확인.

없음.
