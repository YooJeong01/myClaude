## 협업 중 문제 (해결됨)

1. **Codex 세션 OOM 강제 종료** — T28~T33 커밋 후 T34 E2E 실행 중 시스템 메모리 부족으로 프로세스 kill.
   커밋된 작업 유실 없음. Claude 가 미커밋 T34 작업(스택된 파일들) 복구 → 마무리.
2. **로컬 메모리 제약(가용 ~2.5GB / 8GB)** — `pnpm dev` + chromium + (당시) Codex 동시 실행이 OOM.
   → playwright webServer 를 `pnpm start`(프로덕션) 로 변경. 이후 안정.
3. **E2E 셀렉터 버그** — 경험 선택에 `getByText(title)` 사용. 시드 본문이 제목으로 시작해 제목/본문 2개 매칭
   (strict mode violation) → `getByRole("checkbox", { name: title }).check()`.
4. **Gemini 무료 티어 지속 과부하** — `/api/motivation` (UI→LLM) 호출이 실행마다 502(503 매핑). 재시도 헬퍼
   (`submitMotivation`, 502/503 시 15초 후 재시도) 추가. verify-motivation 도 같은 증상을 재시도로 통과했음.
   시나리오 5는 2회차 LLM 호출을 admin draft 시드로 대체(이력 UI 검증이 목적이라 무방).
5. **오프라인 시나리오 설계 오류** — 테스트가 `setOffline` 후 하드 리로드. 서비스워커가 없어(범위 밖)
   문서 자체를 못 받아 앱이 안 뜸. → 리로드 없이 `offline` 이벤트로 `useOnline()` 훅이 미러 모드 전환하는 걸
   검증하도록 수정. (T33 구현은 정상)
6. **serial fail-fast** — LLM 시나리오 하나 실패하면 뒤가 전부 skip. `mode: "default"` 로 변경(`workers=1` 유지).
